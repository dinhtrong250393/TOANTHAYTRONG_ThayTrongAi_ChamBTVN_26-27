📘 CẨM NANG HƯỚNG DẪN TRIỂN KHAI HỆ THỐNG DÀNH CHO GIÁO VIÊN

Hệ thống quản lý ôn tập, thi trắc nghiệm & tự luận thông minh tích hợp trí tuệ nhân tạo (AI Gemini chấm điểm tự động & Tiện ích Zalo tự động báo điểm phụ huynh).

✅ TÍNH ĐỘC LẬP & BẢO MẬT TUYỆT ĐỐI:
Gói mã nguồn này đã được làm sạch toàn bộ dữ liệu cá nhân. Khi Thầy/Cô tiếp nhận và triển khai, toàn bộ dữ liệu học sinh, đề thi và điểm số sẽ được lưu trữ trên tài khoản riêng của chính Thầy/Cô, không bị trùng lặp hay chia sẻ với bất kỳ ai.

Phần 1: Chuẩn bị 3 dịch vụ miễn phí (Chỉ mất 5 phút)

1.1. Lấy mã khóa Google Gemini API (Miễn phí 100%)

  1. Truy cập trang: https://aistudio.google.com/app/apikey
  2. Đăng nhập tài khoản Gmail của Thầy/Cô.
  3. Bấm nút Create API key (Tạo khóa API mới) -> Chọn Create API key in new project.
  4. Sao chép chuỗi ký tự API Key (dạng: MÃ_API_KEY_CỦA_BẠN) và lưu lại.

1.2. Tạo Kho lưu ảnh bài làm học sinh (Cloudinary - Miễn phí)

  1. Truy cập trang: https://cloudinary.com -> Bấm Sign Up For Free.
  2. Sau khi đăng nhập, tại màn hình Dashboard chính, Thầy/Cô sẽ thấy Cloud name (Ví dụ: thayco-storage).
  3. Bấm vào biểu tượng Cài đặt (Bánh răng ⚙️) ở góc dưới bên trái -> Chọn mục Upload (hoặc Upload presets).
  4. Kéo xuống mục Upload presets -> Bấm Add upload preset.
  5. Tại ô Signing Mode: Chuyển từ Signed sang Unsigned (Bắt buộc).
  6. Tại ô Upload preset name: Đặt tên gợi nhớ (Ví dụ: nop_bai_thi).
  7. Bấm Save (Lưu) ở góc trên bên phải.

1.3. Khởi tạo Cơ sở dữ liệu Firebase (Nếu triển khai ngoài Google AI Studio)

  1. Truy cập: https://console.firebase.google.com -> Bấm Add project (Thêm dự án).
  2. Đặt tên dự án -> Bấm Tiếp tục cho đến khi hoàn tất.
  3. Tại menu bên trái:
    • Vào Build -> Authentication -> Bấm Get started -> Chọn tab Sign-in method -> Bật Email/Password và Anonymous.
    • Vào Build -> Firestore Database -> Bấm Create database -> Chọn vị trí (ví dụ: asia-southeast1) -> Bấm Hoàn tất.
  4. Vào Project Settings (Cài đặt dự án ⚙️) -> Kéo xuống mục Your apps -> Bấm biểu tượng Web () -> Sao chép các thông số cấu hình dán vào file firebase-applet-config.json.

Phần 2: Các cách triển khai hệ thống

🚀 Cách 1: Đưa lên Google AI Studio Build (Khuyên dùng - Nhanh & Tự động)

  1. Truy cập: https://ai.studio/build
  2. Bấm nút Import và chọn file nén he-thong-on-thi-thay-co-package.zip (hoặc kết nối qua GitHub).
  3. Google AI Studio sẽ tự động khởi tạo cơ sở dữ liệu và môi trường cho Thầy/Cô.
  4. Vào mục Settings / Secrets -> Thêm biến GEMINI_API_KEY với mã khóa đã lấy ở Bước 1.1.
  5. Hệ thống sẵn sàng hoạt động ngay lập tức!

🌐 Cách 2: Triển khai lên Vercel (Để có tên miền riêng chạy 24/7)

  1. Đăng nhập Vercel.com bằng tài khoản GitHub.
  2. Bấm Add New Project -> Chọn Repository mã nguồn của Thầy/Cô.
  3. Tại mục Environment Variables, nhập 3 biến:
    • GEMINI_API_KEY: Mã khóa lấy ở Bước 1.1.
    • VITE_CLOUDINARY_CLOUD_NAME: Cloud name lấy ở Bước 1.2.
    • VITE_CLOUDINARY_UPLOAD_PRESET: Tên Upload preset lấy ở Bước 1.2.
  4. Bấm nút Deploy. Chờ 1-2 phút là website hoàn tất!

Phần 3: Hướng dẫn cài đặt Tiện ích Zalo (Tự động gửi tin nhắn cho Phụ huynh)

  1. Mở trình duyệt Google Chrome hoặc Cốc Cốc trên máy tính.
  2. Nhập đường dẫn: chrome://extensions/ vào thanh địa chỉ và nhấn Enter.
  3. Gạt công tắc Chế độ dành cho nhà phát triển (Developer mode) ở góc trên bên phải sang BẬT.
  4. Bấm nút Tải tiện ích đã giải nén (Load unpacked) -> Tìm chọn thư mục zalo-extension có trong bộ mã nguồn.
  5. Mở tab mới truy cập Zalo Web: https://chat.zalo.me và đăng nhập Zalo cá nhân của Thầy/Cô.
  6. Trên ứng dụng chấm thi, khi Thầy/Cô chọn gửi báo điểm, hệ thống tự động kết nối với Zalo Web để gửi tin nhắn đến từng phụ huynh.

Phần 4: Bí quyết tối ưu Prompt chấm bài tự luận AI Gemini

Khi tạo đề thi tự luận, Thầy/Cô có thể tùy chỉnh yêu cầu chấm trong ô Đáp án/Biểu điểm chi tiết. Dưới đây là các cấu trúc chuẩn giúp AI chấm chính xác 100%:

Môn Toán / Tự nhiên (Tính toán, logic từng bước):

Yêu cầu chấm:
- Thang điểm tối đa: 10.0 điểm.
- Chia nhỏ thang điểm:
  + Bước 1 (Thiết lập công thức/điều kiện): 2.0 điểm
  + Bước 2 (Các bước biến đổi trung gian): 4.0 điểm
  + Bước 3 (Kết quả cuối cùng & đơn vị): 4.0 điểm
- Chấp nhận các cách giải khác nếu logic đúng. Nếu sai kết quả do tính nhầm ở bước cuối, vẫn cho 70% số điểm các bước trước.

Môn Ngữ văn / Tiếng Anh / Xã hội (Ý tứ, hành văn, lập luận):

Yêu cầu chấm:
- Thang điểm tối đa: 10.0 điểm.
- Tiêu chí đánh giá:
  + Ý tưởng chính & Đúng trọng tâm đề bài: 4.0 điểm
  + Dẫn chứng thuyết phục, lập luận chặt chẽ: 3.0 điểm
  + Ngữ pháp, từ vựng và cách diễn đạt mạch lạc: 3.0 điểm
- Đưa ra nhận xét chi tiết: Chỉ rõ điểm mạnh, điểm cần cải thiện và gợi ý cách hành văn tốt hơn cho học sinh.
